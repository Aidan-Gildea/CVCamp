**This project was created in the Computer Vision ILC at Great Minds Robotics**
This repository contains two .NET projects: 
1. _CVForms:_ A tool made using Windows Forms to quickly assemble a computer vision pipeline by arranging various nodes that can perform standard OpenCV operations and passing mats inbetween the nodes.
2. _CoolProject:_ A demo project that uses a pipeline prototyped in the CVForms tool in order to isolate a pong paddle and detect its bounding box in order to play pong. All values and OpenCV operations in _CoolProject_ were derived from parameters determined in the _CVForms_ project.
